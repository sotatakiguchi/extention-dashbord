# Ignore Files Documentation

This document outlines files and directories that should be ignored in version control and development.

## Git Ignore Patterns

### Dependencies
- `node_modules/` - npm dependencies
- `*.lock` - Lock files (package-lock.json, yarn.lock)

### Build Output
- `dist/` - Distribution builds
- `build/` - Build directory
- `.angular/` - Angular CLI cache

### IDE and Editor
- `.vscode/` - Visual Studio Code settings
- `.idea/` - JetBrains IDE settings
- `*.swp` - Vim swap files
- `*.swo` - Vim backup files
- `.DS_Store` - macOS system files

### Environment
- `.env` - Environment variables
- `.env.local` - Local environment overrides

### Testing
- `coverage/` - Test coverage reports
- `.nyc_output/` - Istanbul coverage output

### Logs
- `logs/` - Application logs
- `*.log` - Log files

### OS Files
- `Thumbs.db` - Windows thumbnails
- `.DS_Store` - macOS system files

## Development Notes
Keep these patterns updated as the project evolves.
